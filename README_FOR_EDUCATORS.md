# 教員向け: 学生のセルフチェック対話記録を教育改善に利用する際の注意

## 基本原則

`AI_Viva` と `greCAPTCHA` は、学生本人による形成的な理解度セルフチェック用です。対話記録は、成績評価、合否、進級、懲戒、AIの不適切利用判定、著者性判定のために設計・検証されたものではありません。

教員が参照する場合は、学生が自発的に提供し、利用目的、閲覧者、保存期間、撤回方法を理解して同意した場合に限り、指導、教材、授業設計、学習支援の改善に利用してください。所属機関の個人情報保護、研究倫理、教育データ、生成AI利用に関する規程を優先してください。

## 適切な利用例

- 学生が説明しにくかった概念を、面談や授業で再説明する
- 複数の学生に共通する誤解を、匿名・集約した形で教材改善へ反映する
- 課題文が曖昧だった箇所や、必要な前提知識が不足していた箇所を見直す
- 学生と相談して、次の学習目標や研究指導上の問いを決める
- 自動フィードバックの誤りを訂正し、情報リテラシー教育に使う

## 避けるべき利用

- 対話スコアを成績へ換算する
- 低得点、無回答、対話拒否を、不正、非著者、AI依存、能力不足の証拠にする
- 学生に対話記録の提出を事実上強制する
- 提出しなかった学生を不利に扱う
- 自動生成された問題・正答・ルーブリックを人間確認なしに正しいとみなす
- 学生間の順位付けや高リスクな個人プロファイリングに使う
- 本来の説明を越えて、研究、懲戒、広報、モデル訓練等へ二次利用する
- 個人名付きの記録をクラス、研究会、第三者へ共有する

## 同意と公平性

学生へ、収集前に平易な言葉で次を説明してください。

1. 利用目的
2. 提供が任意であること
3. 提供しなくても成績や指導上の不利益がないこと
4. 閲覧者と共有範囲
5. 保存場所と保存期間
6. 匿名化または仮名化の方法
7. 撤回、訂正、削除を依頼する方法
8. 自動生成・自動採点には誤りがあり得ること

教員と学生の権力差により、形式的な同意だけでは任意性が確保されないことがあります。可能なら、成績確定後に任意提供を募る、匿名化した振り返りだけを集める、対話記録以外の代替手段を用意するなどの方法を採ってください。

言語、障害、不安、入力速度、専門経験、利用端末、AIへの習熟度が対話へ影響します。学生間比較には使わず、必要な配慮と代替方法を用意してください。

## データ最小化と管理

- 教育改善に必要な部分だけを受け取る
- 氏名、学籍番号、連絡先を可能な限り外す
- 研究参加者、共同研究者、患者、企業等の第三者情報を除く
- 未公開データや機密研究を収集しない
- アクセスできる教職員を限定する
- 保存期限を事前に決め、期限後に安全に削除する
- 生の対話記録より、学生が選んだ抜粋または匿名の振り返りを優先する
- 学外サービスへ移す前に契約、データ所在、機関規程を確認する

授業改善を越えて研究発表や論文化に用いる場合は、教育上の通常利用とは別の目的になる可能性があります。機関の倫理審査、研究同意、データ管理要件を確認してください。

## 記録を読むときの注意

対話記録は、学生の理解そのものではなく、「特定の質問と条件の下で表出した回答」です。

- 提出物との一致と、学問的な正しさを分けて読む
- 問題が学生の担当範囲内だったか確認する
- 問題文の誤前提、曖昧さ、誘導を点検する
- 自動評価が代替解を見落としていないか確認する
- 低い結果の前に、言語、時間、不安、アクセシビリティ、過去の共同分担を検討する
- スコアより、説明、疑問、異議、対話後の修正から学習ニーズを把握する
- AIが「要確認」とした専門内容は、教科書、一次資料、専門家判断で検証する

学生が自動評価に異議を示している場合、その異議自体を理解と批判的判断の証拠として公平に検討してください。

## 推奨ワークフロー

1. 学生へセルフチェックの目的と任意性を説明する。
2. 原則として、学生自身が記録の共有範囲を選ぶ。
3. 個人情報と第三者情報を削除する。
4. 教員が問題、原稿根拠、自動フィードバックを人間として再確認する。
5. 学生との対話で解釈を確認し、AIの判定だけで結論を出さない。
6. 個別支援では具体的な学習行動へ、授業改善では匿名・集約した傾向へ変換する。
7. 合意した期限後に記録を削除する。

## 学生への伝え方の例

```text
この対話記録の共有は任意で、成績や不正判定には使いません。
あなたが選んだ部分だけを、説明が難しかった箇所の指導と教材改善のために読みます。
閲覧者は担当教員に限定し、学期終了後○oか月で削除します。
共有しない場合も不利益はありません。自動フィードバックは教員が再確認します。
```
