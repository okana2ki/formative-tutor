# 学生向け：レポートや研究の理解を、AIとの対話で確かめる

自分のレポートや論文について、AIからの質問に答えます。このやりとりを通して、**自分の言葉で説明できることと、復習が必要なことを見つける**ことができます。これを把握して、レポートや研究対象についての**理解を深める**活動に結びつけます。

試験や成績評価、不正の調査のためのものではありません。誰が文章を書いたか、AIを使ったかを判定するものでもありません。

## 1. 始める前に確認する

- 氏名・学籍番号・連絡先など、理解の確認に不要な**個人情報**は対象ファイルから削除してください。共同研究者や研究参加者、患者、調査協力者などの個人情報は入力しないでください。
- **未公開**の研究資料や秘密情報は、所属先や共同研究のルールで入力が認められているか確認してください。守秘義務や研究倫理上の制限にも従ってください。

## 2. 方式を選んで始める

このプロジェクトでは、**どれくらい理解できているか自動評価するための2つの方式（AI VivaとgreCAPTCHA）** が用意されています。まず、以下の基準により、**どちらの方式を使うか**決めましょう。

| 確かめたいこと | 選ぶ方式 |
|---|---|
| レポートの主張や根拠を、自分の言葉で説明できるか | AI Viva |
| 研究方法を選んだ理由や、その方法がうまくいかない条件など、深い理解が必要な質問に答えられるか | greCAPTCHA |

授業レポートの理解を確認するならAI Viva、卒業研究の方法や分析についての深い理解を確認したいならgreCAPTCHAが目安です。研究レポートでも、まず全体の主張を確認したい場合はAI Vivaを使えます。

このプロジェクトをCodexで開き、**対象ファイルを指定して、選んだ方式の開始文を送ってください**。下の例の `［ファイル名］` は、実際のファイル名や場所に置き換えます。例：`targets/sample/report_sample.docx`

開始文には、方式ごとの指示ファイル（AGENTS.md）を読むよう指定してあります。この行も含めてコピーしてください。

問題数、担当した範囲、確認したい内容、回答中に見る資料は、自分に合わせて変更してください。それ以外の希望は、末尾の「進め方を調整したいとき」を参考に書き加えることができます。理解度の点数を付けて欲しいときはそのように頼んで下さい。

### AI Vivaの開始文

```text
AI Vivaを使います。
AI_Viva/AGENTS.mdを読んで、その指示に従ってください。

対象は［ファイル名］です。
レポートの主張と、その根拠を自分で説明できるか確かめたいです。
4問出してください。各回答の後に、理解できている点と、
復習が必要な点を教えてください。
回答中は、私はこのレポートだけを見ます。
```

### greCAPTCHAの開始文

```text
greCAPTCHAを使います。
greCAPTCHA/AGENTS.mdを読んで、その指示に従ってください。

対象は［ファイル名］です。
私の担当は分析と考察です。実装とデータ収集は担当していません。
分析方法を選んだ理由や、その方法がうまくいかない条件について、
4問出してください。
各回答の後に、理解できている点と、復習が必要な点を教えてください。
回答中は、私はこの研究レポートだけを見ます。
```

## 3. 質問に答える

理由や根拠を、自分の言葉で具体的に説明してください。長い文章や上手な言い回しにする必要はありません。

- **分からないとき**：「ここまでは分かりますが、この部分は説明できません」と伝えてください。
- **質問が分かりにくいとき**：「もう少し分かりやすく言い換えてください」と頼めます。
- **担当していない内容のとき**：「そこは私の担当範囲外です」と伝えてください。
- **質問の前提が間違っていると思うとき**：どこが違うのか、理由とともに説明してください。

回答中に見る資料は、先に決めておきます。検索や別のAIで回答を作ると、自分がどこまで理解しているのか分かりにくくなります。

途中で資料を調べて答え直しても構いません。その場合は「資料を確認してからの回答です」と伝え、最初の回答と区別してください。

## 4. 結果を復習に使う

結果が示すのは、今回の質問と回答、資料の見方などの条件で確認できたことです。あなたの能力全体を示すものではありません。

**点数だけでなく、説明できた点と、説明できなかった点に注目してください。** 説明できなかった点を一つ選び、資料で確認してから、もう一度自分の言葉で説明してみましょう。

結果を見るときは、次のことに注意してください。

- 点数が低くても、本人が書いていないことや、AIを不適切に使ったことの証拠にはなりません。
- 点数が高くても、レポートの内容やデータが正しいこと、同じ方法で研究結果を再現できることの保証にはなりません。レポートに沿った回答でも、レポート自体に誤りがある場合があります。
- AIの質問・採点・助言にも誤りがあります。授業資料や教科書、元の論文などで確かめてください。判断できないときは、指導教員などに相談してください。

## 必要な場合に読む補足

### 進め方を調整したいとき

次の希望があれば、開始文に書き加えてください。すべて指定する必要はありません。

- 授業の学習目標や研究の目的、特に確認したい内容
- 使える時間や問題数
- 回答に使う言語や、必要な配慮
- 各回答の後に助言を受けるか、最後にまとめて受けるか

### 両方の方式を使いたいとき

方式ごとに別の対話を始めてください。例えば、AI Vivaで全体の主張を確認し、greCAPTCHAで研究方法や分析を詳しく振り返れます。

二つの方式は確認する内容が異なります。また、先の対話で得たヒントや疲れが後の回答に影響するため、点数を直接比較したり、平均したりしないでください。

### 対話記録を教員に見せたいとき

記録を見せるかどうかは、原則として自分で決めます。見せる前に、教員へ次を確認してください。

- 何の目的で読むのか。成績評価、不正調査、懲戒には使わないか。
- 誰が読めるのか。いつまで保存するのか。
- 名前を伏せられるか。共有後に取り消しや削除を求められるか。

見せるのは必要な部分だけにし、個人情報や共同研究者に関する情報、未公開データを削除してください。

「見せないと不利益を受ける」と感じる場合は、自由に判断できる状況とはいえません。所属先の相談窓口や担当部署に相談してください。

Codexとの対話内容は、プロジェクトごとのチャット履歴として残っていますが、提出などのためにファイルとして保存したいときは、次のように頼むことができます。「今回の質問・回答・フィードバックを、Markdownファイルとして ［フォルダ名］ に保存してください」。［フォルダ名］は、たとえば、targets/sample のように書きます。targets/sample には、このようにして作成した対話内容の例も置いてあります。
