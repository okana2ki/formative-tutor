### 本文の問題点

「1:5の法則」（2-(1)）  
マーケティングで広く流布している経験則であること自体は事実です。しかし、「古典的な原則」として出典なしで断定されており、元になった実証研究ははっきりしません。倍率も資料によって5倍から25倍程度までばらつきます。事実誤りというより、「通説を確立した事実として扱っている」点が問題です。

LTVの算出式（2-(2)）  
「顧客単価 × 契約継続期間」は大幅に単純化された式を唯一の定義のように書いています。一般には、粗利率を掛ける、獲得・維持コストを差し引く、購買頻度を含めるなどの定義があります。また「顧客単価」が月額なのか年額なのかも曖昧です。

継続顧客とアップセル・口コミの関係（2-(2)）  
継続期間が長い顧客ほどアップセル率が高いという主張に根拠が示されていません。仮にそのような相関があっても、もともと満足度の高い顧客が残っているだけ（選択効果）という可能性があり、因果として書くのは飛躍です。

断定的な表現  
2-(1)の「獲得コストすら回収できず赤字のまま終わってしまう」は、回収期間より前に解約した場合に限られるので、条件付きで書くべき内容です。2-(3)の「解約を未然に防ぐことができる」「不可欠である」も、効果を保証するような言い方になっています。

結論の過大表現（3）  
データも分析もなく一般論を並べただけで「明確になった」と結んでいます。また「単なるコスト削減の手段ではなく」という対比は、本論で一度も論じられていないのに結論で突然出てきます。
